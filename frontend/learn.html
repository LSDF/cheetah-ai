Cybersecurity Learning Paths

Complete beginner-friendly learning paths. Read the lessons in order and practice what you learn in the Challenges section.

Advertisement Space (AdSense Ready)

Lesson 1 — Networking Fundamentals

Everything on the internet moves through networks. Before you can understand hacking or defense, you must understand how data travels.

What you will learn:

  • What an IP address is and why it matters
  • Difference between TCP and UDP
  • Common ports (80, 443, 22, 53, 3389...)
  • How DNS turns names into IP addresses
  • HTTP vs HTTPS

Practice tip: Use the OSINT Tools → DNS and IP lookup to explore real domains and IPs.

Lesson 2 — Linux Basics for Security

Most servers and security tools run on Linux. You need to be comfortable in the terminal.

Key topics:

  • File system structure (/etc, /var, /home, /tmp)
  • Permissions (read, write, execute)
  • Basic commands: ls, cd, cat, grep, find, ps, netstat
  • Users and privileges
  • Why “running as root” is dangerous

Lesson 3 — Web Security Fundamentals

Most modern attacks target web applications. Understanding how websites work is critical.

Core concepts:

  • How browsers talk to servers
  • What cookies and sessions are
  • Introduction to OWASP Top 10
  • XSS and SQL Injection (concept only)
  • Why input validation matters

Never test these ideas on real websites without permission.

Lesson 4 — OSINT (Open Source Intelligence)

OSINT is the art of collecting publicly available information. It is legal when done correctly and extremely useful.

You will learn:

  • Username enumeration across platforms
  • Domain and WHOIS intelligence
  • DNS and infrastructure mapping
  • Public social media footprint analysis
  • How to stay within legal boundaries

Open OSINT Tools →

Lesson 5 — Cryptography Basics

Cryptography protects data. Understanding the basics helps you recognize weak implementations.

Topics:

  • Encoding vs Encryption vs Hashing
  • Base64, Hex, URL encoding
  • Hashing (MD5, SHA family) – one way functions
  • Symmetric vs Asymmetric encryption (simple explanation)

Lesson 6 — Ethical Hacking Mindset

Tools are useless without the right mindset and legal understanding.

Key principles:

  • Only test systems you own or have written permission to test
  • Responsible disclosure
  • Scope is everything
  • Document everything
  • Think like an attacker, act like a professional

Recommended Order

1. Networking → 2. Linux → 3. Web Security → 4. OSINT → 5. Cryptography → 6. Ethical Mindset

After each lesson, go to the Challenges page and practice.
